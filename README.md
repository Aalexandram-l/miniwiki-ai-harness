# MiniWiki

MiniWiki — лёгкое веб-приложение для создания, редактирования, организации и поиска wiki-страниц.

Проект разрабатывается с использованием Python и FastAPI. В качестве пользовательского интерфейса используются серверные HTML-шаблоны и HTMX.

## Цели проекта

- Создание и редактирование wiki-страниц.
- Поиск и организация страниц.
- Поддержка тегов и связей между страницами.
- Безопасная обработка Markdown.
- Предоставление REST API.
- Поддержка аутентификации и разграничения прав доступа.

## Технологический стек

- Python 3.12
- FastAPI
- SQLite
- SQLAlchemy
- Jinja2
- HTMX
- Pytest
- Ruff
- Docker

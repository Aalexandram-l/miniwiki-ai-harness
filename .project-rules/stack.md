# Правила технологического стека

## Основной стек

- Основной язык проекта — Python 3.12.
- Для автоматизированного тестирования используется pytest.
- Для проверки качества кода используется Ruff.
- Конфигурация проекта хранится в `pyproject.toml`.
- Зависимости проекта фиксируются в `requirements.txt` и `requirements-dev.txt`.

## Структура проекта

- `app/` — основное приложение MiniWiki.
- `ai_harness/` — компоненты AI Harness.
- `tests/` — автоматизированные тесты.
- `docs/` — документация проекта.
- `.project-rules/` — проектные правила.
- `docs/ai/` — файлы сохранения контекста между сессиями.

## Управление зависимостями

- Не добавлять новые зависимости без обоснования.
- Перед добавлением зависимости описать причину, альтернативы и принятое решение в `docs/ai/DECISIONS.md`.
- Предпочитать стандартную библиотеку Python, если она решает задачу без неоправданных усложнений.
- Не обновлять зависимости без необходимости и проверки совместимости.

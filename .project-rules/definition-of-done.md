# Критерии готовности задачи

Задача считается завершённой, если выполнены все применимые требования:

## Реализация

- Реализованы все пункты согласованного плана.
- Изменения соответствуют архитектуре и технологическому стеку проекта.
- Не затронуты посторонние файлы.
- Не добавлены необоснованные зависимости.
- Обработаны ожидаемые ошибочные ситуации.

## Проверка качества

- Все автоматизированные тесты проходят успешно.
- Новая функциональность покрыта тестами.
- Проверки Ruff проходят без ошибок, если изменялся Python-код.
- Изменения не нарушают существующую функциональность.

## Документация

- Документация обновлена, если изменились архитектура, поведение или интерфейсы компонентов.
- Значимые решения внесены в `docs/ai/DECISIONS.md`.
- Новые известные проблемы внесены в `docs/ai/GOTCHAS.md`.

## Завершение

- `docs/ai/PROGRESS.md` обновлён.
- Изменения проверены через Git.
- Нет случайно добавленных секретов, временных файлов и локальных настроек.
- Коммит создаётся только после успешного прохождения проверок.

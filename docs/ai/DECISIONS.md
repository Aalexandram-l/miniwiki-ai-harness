# Журнал архитектурных решений

## ADR-001. Основной язык проекта

**Решение:** использовать Python 3.12.

**Альтернативы:** Python 3.11 и более ранние версии Python.

**Причина:** современная версия Python с поддержкой актуальных возможностей языка и совместимостью с выбранными инструментами разработки.

## ADR-002. Локальное хранение памяти

**Решение:** использовать JSON-файл для хранения записей AI Harness.

**Альтернативы:** SQLite и внешняя база данных.

**Причина:** JSON прост в реализации, не требует дополнительной инфраструктуры и подходит для текущего прототипа.

## ADR-003. Разделение AI Harness на компоненты

**Решение:** разделить правила, память и управление контекстом на отдельные модули.

**Альтернативы:** единый класс, содержащий всю логику.

**Причина:** разделение ответственности упрощает тестирование, сопровождение и дальнейшее развитие.

## ADR-004. Управление зависимостями

**Решение:** не добавлять новые зависимости без предварительного обоснования в этом файле.

**Альтернативы:** свободное добавление библиотек по мере необходимости.

**Причина:** контроль сложности проекта, совместимости и внешних зависимостей.

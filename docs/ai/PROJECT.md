# MiniWiki — описание проекта

## Назначение

MiniWiki — проект веб-приложения для организации и представления знаний. Проект разрабатывается на Python. AI Harness содержит вспомогательные компоненты для управления правилами, локальной памятью и контекстом.

## Технологический стек

- Python 3.12.
- pytest — автоматизированное тестирование.
- Ruff — проверка качества и форматирования Python-кода.
- JSON — локальное хранение записей памяти AI Harness.
- Конфигурация — `pyproject.toml`.

## Структура проекта

- `app/` — основное приложение MiniWiki.
- `ai_harness/rules/` — движок правил.
- `ai_harness/memory/` — управление локальной памятью.
- `ai_harness/context/` — сборка контекста.
- `tests/` — автоматизированные тесты.
- `docs/architecture/` — архитектурная документация.
- `docs/ai-harness/` — документация компонентов AI Harness.
- `docs/ai/` — сохранение контекста между рабочими сессиями.
- `.project-rules/` — правила разработки проекта.

## Архитектура AI Harness

1. RuleEngine проверяет запросы по набору правил.
2. MemoryManager сохраняет и извлекает записи локальной памяти.
3. ContextManager формирует контекст из запроса и доступных записей памяти.

## Ограничения текущей реализации

- Движок правил использует поиск ключевых слов и не выполняет семантический анализ.
- Память хранится локально в JSON-файле.
- Контекст ограничивается количеством символов, а не токенов.
- Компоненты AI Harness являются прототипом и не заменяют полноценные механизмы безопасности.

## Принципы разработки

- Следовать правилам из `.project-rules/`.
- Покрывать новую функциональность тестами.
- Не добавлять зависимости без документированного обоснования.
- Обновлять документацию при изменении архитектуры.

# Известные проблемы и способы их решения

## Python и виртуальное окружение

**Проблема:** команда `python` может запускать не ту версию Python.

**Решение:** использовать Python 3.12 и локальный интерпретатор виртуального окружения:

`.\.venv\Scripts\python.exe`

## Git

**Проблема:** Git может определить неправильную корневую папку репозитория, если `.git` находится выше каталога проекта.

**Решение:** проверить корень командой:

`git rev-parse --show-toplevel`

Корень должен указывать на каталог `miniwiki-ai-harness`.

## Pytest и импорты

**Проблема:** файл `tests/ai_harness/__init__.py` может конфликтовать с импортом основного пакета `ai_harness`.

**Решение:** не создавать `__init__.py` внутри `tests/ai_harness/`, если он не требуется настройками тестовой структуры.

## Ruff

**Проблема:** Ruff может сообщать о нарушениях форматирования или рекомендациях по современному синтаксису Python.

**Решение:** выполнить:

`.\.venv\Scripts\python.exe -m ruff check ai_harness tests`

`.\.venv\Scripts\python.exe -m ruff format ai_harness tests`

После форматирования повторно запустить тесты и проверку Ruff.

# Управление контекстом AI Harness

## 1. Назначение

Context Manager формирует текстовый контекст для дальнейшей обработки пользовательского запроса.

Контекст объединяет исходный запрос и доступные записи локальной памяти.

## 2. Структура Context

Объект `Context` содержит:

- `user_query` — исходный запрос пользователя;
- `memory_items` — выбранные записи памяти;
- `text` — итоговый текст контекста.

## 3. ContextManager

Основной класс принимает:

- экземпляр `MemoryManager`;
- `max_chars` — максимальный размер контекста в символах.

Метод `build()` формирует контекст.

## 4. Алгоритм формирования

1. Проверяется, что запрос не пустой.
2. Запрос добавляется в начало контекста.
3. Менеджер получает записи локальной памяти.
4. Записи добавляются, пока не превышен лимит символов.
5. Формируется итоговый объект `Context`.

## 5. Ограничения

Размер контекста измеряется в символах, а не в токенах языковой модели.

Текущая реализация не использует специализированный токенизатор и не выполняет семантический отбор релевантных воспоминаний.

## 6. Тестирование

Проверяются формирование контекста с памятью и без неё, соблюдение ограничения размера и обработка некорректных параметров.

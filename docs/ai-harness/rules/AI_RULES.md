# Система правил AI Harness

## 1. Назначение

Rule Engine — компонент AI Harness, который проверяет пользовательские запросы на соответствие заданным правилам.

На текущем этапе реализована базовая проверка текста по ключевым словам.

## 2. Основные компоненты

### RuleAction

Перечисление возможных действий:

- `ALLOW` — правило разрешает запрос.
- `DENY` — правило запрещает запрос.

### Rule

Структура отдельного правила содержит:

- `name` — уникальное имя;
- `description` — описание;
- `action` — действие правила;
- `keywords` — список ключевых слов.

### RuleResult

Результат проверки содержит:

- `allowed` — разрешён ли запрос;
- `matched_rules` — список совпавших правил;
- `reason` — причина результата.

### RuleEngine

Основной класс движка правил.

Поддерживает:

- добавление правил;
- проверку пользовательского текста;
- обнаружение запрещённых ключевых слов;
- отклонение пустых запросов;
- проверку уникальности имён правил.

## 3. Принцип работы

1. Пользователь передаёт текст запроса.
2. Движок проверяет, не является ли запрос пустым.
3. Текст сравнивается с ключевыми словами правил.
4. Если найдено запрещающее правило, запрос отклоняется.
5. Если запрещающих совпадений нет, запрос разрешается.

## 4. Ограничения текущей реализации

Текущая версия использует простое сравнение подстрок без семантического анализа.

Это прототип, а не полноценный механизм информационной безопасности. Он не распознаёт смысл запроса, обходы правил или контекстные угрозы.

## 5. Тестирование

Проверяются:

- отклонение пустого запроса;
- разрешение запроса без совпадений;
- блокировка запрещённого ключевого слова;
- отклонение повторного добавления правила.

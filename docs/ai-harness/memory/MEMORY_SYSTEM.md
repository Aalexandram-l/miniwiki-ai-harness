# Система памяти AI Harness

## 1. Назначение

Memory Manager отвечает за хранение и управление информацией, которую AI Harness может использовать при формировании контекста.

Данные сохраняются локально в формате JSON.

## 2. Структура записи

Каждая запись представлена объектом `MemoryEntry`:

- `id` — уникальный идентификатор;
- `content` — содержимое;
- `category` — категория записи.

## 3. Возможности MemoryManager

Реализованы следующие операции:

- `add()` — добавление записи;
- `get_all()` — получение всех записей;
- `get_by_category()` — поиск по категории;
- `delete()` — удаление записи по идентификатору.

## 4. Хранение данных

Для хранения используется JSON-файл.

При создании менеджера данные загружаются из указанного файла. При изменении памяти обновлённое содержимое записывается во временный файл, который затем заменяет основной.

## 5. Проверка данных

Менеджер отклоняет:

- пустое содержимое записи;
- пустую категорию.

## 6. Ограничения

Текущая версия не предусматривает шифрование, разграничение доступа и автоматическое удаление устаревших записей.

Не следует сохранять пароли, API-ключи и другие секретные данные.

## 7. Тестирование

Проверяются добавление, получение, сохранение, фильтрация и удаление записей, а также обработка пустого содержимого.
